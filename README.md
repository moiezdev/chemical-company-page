# NexChem Chemicals

Static React site for a specialty chemical distributor (inspired by rainbowchemical.com).

## Pages

- `/` — Home
- `/about` — About
- `/contact` — Contact Us

## Data

Content lives in `src/data/*.json` and is passed into components as props. Images are in `public/images/`.

## Run

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
npm run preview
```
